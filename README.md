# Roteiro Vitória

Roteiro de viagem responsivo para Vitória e Vila Velha, preparado como uma página HTML estática para celular.

## Abrir localmente

Abra o arquivo `index.html` em qualquer navegador. Fotos, mapas e links externos precisam de conexão com a internet.

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório no GitHub.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde o endereço público ser gerado.
